# Voice Input 0.4.0

## Что нового

- Каталог дополнительных локальных моделей GigaAM v3 E2E и Nemotron 3.5 ASR с русской пунктуацией. Их веса загружаются отдельно по кнопке и не входят в установщик или portable-архив.
- Пауза, продолжение и отмена загрузок. Полученные файлы сохраняются после разрыва соединения и закрытия приложения. После скачивания виден отдельный этап «Проверка файлов» с прогрессом; модель доступна только после проверки всех контрольных сумм. Прерванную проверку можно продолжить без повторного скачивания.
- Сохранение основной модели, удаление скачанных моделей и выбор сохранения моделей и настроек при деинсталляции.
- Тяжёлое распознавание выполняется отдельно от обработки звука и индикатора уровня.
- В компактном режиме весь текст доступен прокруткой; новые фразы автоматически видны внизу, ручное чтение предыдущих строк сохраняет позицию.
- Настроен CPU runtime для GigaAM/Nemotron: ограниченный бюджет потоков и отсутствие активного ожидания между задачами. В каталоге явно указаны существующие INT8-варианты; скачивать веса повторно не требуется.
- Завершённые фразы добавляются с новой строки; текущую запись можно очистить во время диктовки. Переносы передаются текстом, без нажатия Enter.

**Переход:** новые модели нужно загрузить вручную на вкладке «Модель». При обновлении скачанные модели и настройки сохраняются. Нативное распознавание работает на CPU; подходящую модель и задержку нужно оценить на своём компьютере.
