## Что нового

- Добавлен `voice-input-cli.exe` для управления уже запущенным приложением из терминала и сторонних программ. Команды: состояние, запуск/остановка диктовки, каталог и выбор установленной модели, чтение и смена/очистка записей, проверка микрофона, показ/скрытие окна и выход. Ответы в JSON, локальный Windows named pipe, без сетевого сервера и автоматических повторов команд.
- Настоящий выход теперь блокирует новые сеансы и дожидается завершения рабочего потока распознавания и освобождения модели. CLI `stop` также ждёт освобождения модели. Крестик по-прежнему скрывает окно в трей; обычная диктовка при скрытии продолжается.
- Ошибка асинхронного запуска микрофона или модели доступна в CLI `status`.
- CLI включён в установщик и portable-пакет; обновлено руководство.

**Переход с 0.4.2 и старше:** установленную NSIS-версию можно обновить через настройки приложения или новым установщиком. Для portable первый переход на 0.4.3 выполните вручную: выйдите из Voice Input и распакуйте новый ZIP в отдельную папку либо поверх прежней копии. Старый portable-обновлятор отклонит новый файл `voice-input-cli.exe`. Скачанные модели и настройки в AppData сохраняются. Пакеты подписаны прежним ключом.
