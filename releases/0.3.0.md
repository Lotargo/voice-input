## Скачать

- **[Portable ZIP](https://github.com/Lotargo/voice-input/releases/download/v0.3.0/Voice-Input-Portable-windows-x64.zip)** — распакуйте папку `Voice-Input` целиком и запустите `voice-input.exe`. Установка не требуется.
- **[Установщик Windows x64](https://github.com/Lotargo/voice-input/releases/download/v0.3.0/Voice-Input-Setup-windows-x64.exe)** — установит приложение с ярлыками и удалением через Windows.

Для portable необходим Microsoft WebView2 Runtime. Windows 10/11 x64.

## Что нового

- «Параметры → Звук»: выбор конкретного микрофона или устройства Windows по умолчанию. Выбор сохраняется между запусками.
- При отключении выбранного микрофона диктовка останавливается с понятным сообщением. Распознанный текст сохраняется в текущей записи; приложение не переключается на другой микрофон самостоятельно.
- Проверка уровня до 20 секунд: исходный сигнал и сигнал после обработки, предупреждение о тихом звуке и цифровой перегрузке. Проверка не распознаёт речь, не вставляет текст и не сохраняет аудио.
- Отключаемое локальное шумоподавление для постоянного шума: фильтр низкого гула и RNNoise через nnnoiseless. Работает на CPU, по умолчанию выключено. Перегрузка исходного микрофона остаётся видимой после обработки.
- Настройки разделены на «Звук», «Диктовка» и «Обновления». Кнопка микрофона внизу окна открывает настройки звука.

**Переход с 0.2:** после публикации релиза обновление доступно через «Параметры → Обновления». Portable остаётся в своей папке, установленная версия обновляется через NSIS. С версии 0.1 скачайте новую сборку вручную один раз.

Перед сменой микрофона или шумоподавления остановите диктовку и проверку уровня. Перед обновлением скопируйте нужные записи: редактор, история и очередь хранятся в памяти. Диктовка и обработка звука остаются локальными.

Подписи `.sig` проверяются приложением; `SHA256SUMS.txt` содержит контрольные суммы. Подпись обновлений не является сертификатом Authenticode: Windows SmartScreen может показывать предупреждение.
