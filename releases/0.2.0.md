## Скачать

- **[Portable ZIP](https://github.com/Lotargo/voice-input/releases/download/v0.2.0/Voice-Input-Portable-windows-x64.zip)** — распакуйте папку `Voice-Input` целиком и запустите `voice-input.exe`. Установка не требуется.
- **[Установщик Windows x64](https://github.com/Lotargo/voice-input/releases/download/v0.2.0/Voice-Input-Setup-windows-x64.exe)** — установит приложение с ярлыками и удалением через Windows.

Для portable необходим Microsoft WebView2 Runtime. Windows 10/11 x64.

## Что нового

- «Параметры → Обновления»: ручная проверка GitHub Releases, загрузка с проверкой подписи и перезапуск.
- Portable обновляет файлы в своей папке, сохраняя формат portable. Установленная версия обновляется через NSIS.
- Раздельные каталоги portable, установщиков и метаданных релиза; версии SemVer и теги `vX.Y.Z`.
- Компактный интерфейс, необязательный редактор, история записей и собственная горячая клавиша.
- Одна запись продолжается после пауз; боковые кнопки очистки и новой записи. Необязательное разделение после 1–60 секунд тишины.
- Живая волна реагирует на громкость и частоты, предупреждает о перегрузке.

**Переход с 0.1:** скачайте 0.2.0 вручную один раз. В старой версии проверки обновлений ещё нет. Последующие версии проверяются внутри приложения.

Обновление выполняется только по вашей команде. Перед перезапуском скопируйте нужные записи: редактор, история и очередь хранятся в памяти. Диктовка остаётся локальной и не отправляется в сеть.

Подписи `.sig` проверяются самим приложением. `SHA256SUMS.txt` позволяет дополнительно проверить скачанные файлы. Подпись обновлений не является сертификатом Authenticode: Windows SmartScreen может показывать предупреждение для нового приложения.
