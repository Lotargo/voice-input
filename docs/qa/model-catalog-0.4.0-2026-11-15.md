# Каталог моделей Voice Input 0.4.0

Дата: 2026-11-15. Локальная Windows-сборка, CPU Intel Core i7-10750H. Публикация релиза не выполнялась.

## Реализованный сценарий

Vosk Small RU остаётся в комплекте. GigaAM v3 E2E и Nemotron 3.5 ASR пользователь скачивает вручную из встроенного каталога. Карточки показывают описание, размер файлов, состояние и действия. Выбор основной модели сохраняется нативно и используется горячей клавишей при скрытом окне. Пользовательские папки Vosk каталог не удаляет; пропавшая основная модель не заменяется автоматически.

Размер GigaAM: 231 898 272 байта. Размер Nemotron: 682 215 356 байт. URL, версии, размеры отдельных файлов и SHA-256 закреплены в [model-catalog.json](../../src-tauri/model-catalog.json). Веса этих моделей не включены в ресурсы установщика и portable. Во время запуска каталог не обращается к Hugging Face.

Загрузчик сохраняет частичные файлы, использует подтверждённый HTTP Range и не перезаписывает сохранённое начало, если сервер проигнорировал диапазон. Пауза, разрыв соединения и закрытие приложения оставляют данные для продолжения. Отмена удаляет только незавершённую управляемую загрузку.

После скачивания **всех файлов** начинается отдельный этап «Проверка файлов». Карточка показывает объём проверенных данных. Основной модель можно назначить только после успешной проверки каждого SHA-256 и атомарного переноса каталога. Пауза проверки сохраняет файлы; после перезапуска кнопка «Проверить» запускает проверку сохранённых данных без повторной загрузки. Хеширование после перезапуска начинается заново. Открытая вкладка сверяет статус с локальным нативным загрузчиком каждую секунду, чтобы восстановиться после пропущенного события; эти запросы не выходят в сеть.

## Проверки загрузчика и интерфейса

- `cargo fmt --all` выполнен.
- `cargo test --locked -- --test-threads=1`: 56 модульных и 2 интеграционных теста прошли. Включены настоящий Vosk, синтетический PCM/VAD, очередь тяжёлого декодирования, отключение телеметрии ORT и скрытые нативные поля Windows.
- `node --test scripts/test-ui.cjs scripts/test-models.cjs`: 65 тестов прошли. Проверяются отдельный прогресс проверки, отсутствие ранней доступности, продолжение после перезапуска, восстановление пропущенного события локальным снимком, защита от старых снимков и остановка опроса скрытой вкладки.
- Локальный HTTP-сервер обрывал передачу на 8192 байтах. Новый экземпляр каталога запросил ровно `Range: bytes=8192-` и собрал исходный файл. Отказ сервера от Range не повредил префикс.
- Испорченный завершённый файл не стал установленной моделью. Проверка была приостановлена из обработчика прогресса, после перезапуска завершилась без сетевого сервера. Проверено, что все байты приходят до начала хеширования, а доступность появляется последней.
- На настоящей GigaAM принудительный выход QA-процесса с кодом 88 сохранил 8 337 420 байт. Приложение обнаружило загрузку как приостановленную; продолжение, ручная пауза и установка прошли в нативном интерфейсе.
- Обе настоящие модели скачаны и проверены. Дополнительно их полные файлы скопированы в изолированную незавершённую загрузку: обе прошли путь `verifying → installed` без повторного скачивания. Рабочие папки моделей не изменялись.
- Пересобранный интерфейс обнаружил обе модели и сохранил текущую основную модель.

Журналы находятся в `dist/qa/models/`: `rust-tests.log`, `ui-tests.log`, `giga-crash.log`, `verification-copy-20261115-060613/`.

## Проверка распознавания

Четыре фразы синтезированы локально Windows SAPI на русском языке, mono 16 kHz. Микрофон не использовался. Файлы пропущены через производственный VAD и нативные CPU-распознаватели. Восемь результатов, загрузка моделей, время декодирования и пиковая рабочая память сохранены в `dist/qa/models/recognition/results.json`. Скрипт: [test-model-recognition.ps1](../../scripts/test-model-recognition.ps1).

| Исходная фраза | GigaAM | Nemotron |
| --- | --- | --- |
| Идентификация пользователя и реализация алгоритма завершены. | Точное совпадение. | «Идентификация пользователя и реализации алгоритма завершены» |
| Система поддерживает аутентификацию, сериализацию и многопоточную обработку. | Точное совпадение. | «Система поддерживает аутентификацию, сериацию и многопоточную обработку» |
| Диаметр заготовки двадцать миллиметров, допуск пять сотых миллиметра. | «Диаметр заготовки 20 мм, допуск — 5 мм.» | «Диаметр заготовки 20 миллиметров.  Допуск 5 мм» |
| После проверки соединения загрузка продолжается с сохранённого места. | Лишняя запятая после «соединения». | Корректные слова, без конечной точки; «сохраненного» без ё. |

На этих записях GigaAM декодировала 5,48–7,255 с аудио за 0,55–0,66 с, загрузка модели занимала 1,10–1,27 с, пиковая рабочая память процесса 281,5–283,1 МиБ. Nemotron: 1,73–2,13 с декодирования, 1,98–2,44 с загрузки, 759,7–759,8 МиБ; выдавались 8–11 предварительных гипотез. Эти измерения относятся к синтетическим файлам и данному CPU, не являются замером задержки микрофонной диктовки.

**Обнаруженное ограничение:** обе модели потеряли слово «сотых» и превратили допуск 0,05 мм в 5 мм. Числа и технические значения требуют ручной проверки. Малый набор синтетической речи не доказывает общее превосходство одной модели, точность живой речи или корректность всех технических терминов.

## Сборка и границы проверки

Локальная сборка `cargo tauri build --bundles nsis` выполняется с конфигурацией `dist/qa/models/local-build.json`, отключающей создание подписанного артефакта обновления. Приватный ключ обновлений в ожидаемой локальной папке отсутствует. Новый ключ не создавался, встроенный публичный ключ не менялся. Тестовый пакет не предназначен для публикации как подписанное обновление.

Интерактивный вопрос NSIS проверен отдельным безопасным стендом, включающим настоящий `installer-hooks.nsh`: он записывает только выбранный флаг, не удаляет данные. «Да, сохранить» даёт флаг удаления 0; «Нет, удалить» даёт 1. Для обновления и тихого удаления подтверждён флаг 0. Результаты: `dist/qa/models/nsis-hooks/result-*.txt`. Удаление рабочей установки и её пользовательских данных не выполнялось.

Живая диктовка через микрофон и полный ручной набор внешних редакторов на этой версии агентом не проверялись. Сохраняются ограничения UI Automation и отсутствие подтверждения приёма текста со стороны Windows SendInput.
