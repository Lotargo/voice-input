# Подготовка Voice Input 0.4.1

Дата: 2026-11-15. Выпуск объединяет каталог локальных моделей, возобновляемые загрузки с видимой проверкой файлов, прокрутку компактного текста и CPU-профиль распознавания. Номер 0.4.1 выбран для обновления в том числе с локальных тестовых сборок 0.4.0. Предыдущий публичный релиз: 0.3.0.

## Исправление перед выпуском

В тестовой 0.4.0 путь к CPU-профилю определялся относительно аргумента Vosk DLL, но обычный запуск GigaAM/Nemotron передавал пустой путь. QA-оболочка использовала явно заданный путь и не воспроизводила этот участок запуска.

В 0.4.1 поиск файла runtime выполняется по выбранному движку: Vosk получает DLL, GigaAM/Nemotron получают `models/CPU-Execution.conf`. Оба расположения, `resources/models/` у установленной версии и `models/` у portable, проверены отдельным тестом без Vosk DLL. Файл проверяется до перехода в состояние записи. QA-оболочка использует тот же поиск, что и приложение.

## Выполненные проверки исходников

- `cargo fmt --all` и проверка пробелов в Git.
- `cargo test --locked -- --test-threads=1`: 58 модульных и 2 интеграционных теста прошли. Среди них возобновление HTTP Range, прерываемая проверка SHA-256, порядок очереди декодирования, пути runtime, генерации записей и отсутствие Enter при вставке.
- `node --test scripts/test-ui.cjs scripts/test-models.cjs`: 67 проверок прошли. Проверяются отдельное состояние проверки файлов, восстановление потерянного события, прокрутка к свежему тексту и сохранение места ручного чтения.
- Настоящие GigaAM и Nemotron загружены через производственный поиск runtime и обработали прежнюю синтетическую техническую фразу. Использованы 4 потока и профиль без spinning. Журнал: `dist/qa/models/runtime-discovery-0.4.1.jsonl`.
- Пробная подпись с защищённой версией 0.4.1 проверена исходным публичным ключом. Ключ обновления не менялся, приватный материал остаётся вне Git.

Подробные результаты распознавания и ограничения: [каталог моделей](./model-catalog-0.4.0-2026-11-15.md), [CPU-профиль](./recognition-performance-2026-11-15.md). Числовые ошибки распознавания из этих проверок сохраняются.

## Пакеты и публикация

Штатная сборка: `scripts/build-windows.ps1 -SkipPrepare`. Публикация: `scripts/publish-release.ps1` после проверки исходного коммита, пакетов, подписей и контрольных сумм.

- Portable ZIP и подпись: `dist/portable/0.4.1/`.
- NSIS и подпись: `dist/installers/0.4.1/`.
- `latest.json`, `latest-portable.json`, `SHA256SUMS.txt`, коммит сборки: `dist/releases/0.4.1/`.
- Результаты проверки состава, версий и подписей пакетов после сборки: `dist/qa/release-0.4.1-verify/results.json`.

В дополнительные модели входят закреплённые INT8-экспорты. Их веса остаются вне пакетов приложения и не меняются при этом выпуске; повторная загрузка установленных моделей не нужна.

Переход с текущей версии через интерфейс обновления по просьбе владельца оставлен ему для самостоятельной проверки. Установка обновления и живая микрофонная диктовка в подготовке выпуска агентом не запускаются. Проверка опубликованных метаданных и подписей не заменяет эту ручную проверку перехода.
