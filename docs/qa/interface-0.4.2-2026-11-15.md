# Каталог, настройки и README 0.4.2

Дата: 2026-11-15. Изменения подготовлены в ветке main; опубликованный релиз на момент проверки — 0.4.1.

## Каталог моделей

Список основной модели строится из того же каталога, что и карточки. Повторное сканирование папок для списка выбора удалено. Поиск встроенного Vosk возвращает только одну предпочтительную копию `vosk-model-small-ru-0.22`, даже когда одновременно существуют ресурсы установленной и разрабатываемой версий. Имена произвольных папок не добавляются в каталог.

Поле «Своя модель Vosk» удалено. Backend принимает только пути встроенной модели или установленных моделей из закреплённого каталога. Сохранённая ранее пользовательская модель блокируется с предложением явно выбрать поддерживаемую. Её файлы не удаляются, автоматической подмены основной модели нет. Каноническая запись пути к той же встроенной папке нормализуется, чтобы не создавать ложного состояния недоступности. После выбора поддерживаемой модели предупреждение снимается.

## Геометрия настроек

У разделов «Звук», «Диктовка» и «Обновления» общие верхний отступ, высота строки первой подписи, интервал перед контролом и высота первого поля/кнопки 36 px.

На трёх предоставленных скриншотах 482 × 482 px пиксели основного цвета текста первой подписи занимают одинаковые строки 209–214. Проверка выполнялась в одинаковой области изображения и с одинаковым порогом цвета. Снимки сохранены без изменений в `docs/assets/screenshots/`.

## README

Добавлены локальный SVG-баннер в палитре приложения, шильдики, ссылки на сборки, галерея из шести предоставленных скриншотов и блок добровольной поддержки ЮMoney. Номер кошелька сохранён в указанном формате. Кнопка ведёт на официальную страницу переводов, получатель вводится по номеру из README. Платёжные действия не выполнялись.

Подробный прежний текст сохранён в [руководстве](../manual.md), относительные ссылки исправлены. Убраны устаревшие инструкции по произвольной модели; различие между main и опубликованным релизом указано явно. Для скриншотов с изменённой горячей клавишей и режимом разработки добавлена подпись.

По решению владельца для исходного кода добавлена лицензия MIT с правообладателем Lotargo. SPDX-идентификатор указан в Cargo.toml, шильдик и ссылки добавлены в документацию. Текст из корневого LICENSE автоматически копируется при сборке в уведомления установщика и portable; сторонние лицензии сохраняются отдельно.

Проверка локального HTML-предпросмотра README в headless Edge: все изображения загрузились, локальные ссылки существуют, версия для узкого окна также отрисована. Все шесть исходных PNG скопированы с совпадением SHA-256; номер ЮMoney проверен точным сравнением. Артефакты: `dist/qa/readme/readme-desktop.png`, `readme-mobile.png`, `banner-rendered.png`, `results.json`.

## Автоматические проверки

- Итоговые 60 модульных и 2 интеграционных Rust-теста прошли.
- Проверки каталога включают блокировку старой своей модели, нормализацию канонического пути и отсутствие подмены сохранённого выбора.
- 68 UI-тестов прошли, включая снятие предупреждения после выбора поддерживаемой модели и защиту списка выбора от запоздавшего снимка после завершения загрузки.
- Проверки README не используют микрофон, обновление установленного приложения или пользовательские записи. Скриншоты для итогового README предоставлены владельцем.

Сборка Windows выполняется штатным `scripts/build-windows.ps1 -SkipPrepare`; результаты и подписи размещаются в `dist/*/0.4.2/`. Публикация нового релиза не входит в эту итерацию.
