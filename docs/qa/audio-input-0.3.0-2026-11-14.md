# Voice Input 0.3.0 — проверка настроек звука

Дата: 2026-11-14. Среда: Windows x64. Статус: автоматические проверки пройдены; проверка живого микрофона исключена по просьбе пользователя.

## Реализованный объём

Выбор микрофона по идентификатору с сохранением настройки, обработка потери устройства без неявной подмены, проверка уровня до 20 секунд и отключаемое локальное шумоподавление. Остальные улучшения звука в эту версию не включены. По умолчанию используется устройство Windows, шумоподавление выключено.

Обработка выполняется в рабочем потоке: ресемплинг с фильтром от наложения спектров; при включённом шумоподавлении — 100 Гц high-pass и nnnoiseless/RNNoise на 48 кГц, затем 16 кГц для VAD/Vosk. Исходные RMS, пик и доля отсчётов у границы диапазона измеряются до фильтров. Проверка уровня использует этот же тракт без Vosk и доставки текста.

## Результаты

| Проверка | Результат |
| --- | --- |
| `cargo fmt --check` | Пройдена |
| `cargo test --locked` | 41 модульный тест и 2 интеграционных теста настоящего Vosk, без ошибок |
| `node --check ui/audio.js`, `node --check ui/app.js` | Пройдены |
| `node --test scripts/test-ui.cjs` | 52 теста, без ошибок |
| Headless Edge, основной интерфейс | Продолжение записей, Next/Clear, история, таймер, редактор, горячая клавиша, волна и обновления — пройдены |
| Headless Edge, раздел «Звук» | Выбор устройства, сохранение/откат шумоподавления, уровни, исходная перегрузка, остановка проверки, клавиатурные вкладки, недоступное устройство, окно 480 × 480 — пройдены |

Тесты сохранения проверяют непрозрачный идентификатор устройства и атомарную замену JSON-файла. Ошибка записи не изменяет действующую настройку. Вход, выбранный явно, при недоступности не заменяется устройством по умолчанию.

Потеря потока проверена подменой источника: после остановки захвата принятые PCM-кадры обрабатываются, завершающий текст сохраняется до сообщения об ошибке. Отдельно проверено, что режим проверки уровня не создаёт транскрипции и границы записей. UI-тесты охватывают уход из раздела во время незавершённого запуска проверки и защиту от запоздавших событий.

Регрессия шумоподавления использует синтетическую русскую речь с добавленными постоянным шумом и гулом 90 Гц. После обработки RMS шумового участка составил 0,007398 вместо 0,013021, примерно на 4,9 дБ ниже; настоящий Vosk сохранил все шесть проверяемых слов. Это результат конкретного воспроизводимого сигнала, а не оценка качества для всех микрофонов и помещений. Аудиофикстура создана синтезатором Windows; пользовательская речь не записывалась.

## Границы проверки и упаковка

Физическое отключение USB-микрофона и реальное шумное окружение в этой проверке не использовались. Проверку захвата живого микрофона пользователь явно исключил. Проверки интерфейса подменяют нативные команды и не обращаются к микрофону, очереди ввода Windows или системному буферу обмена.

Сборка выполняется `scripts/build-windows.ps1 -SkipPrepare`: отдельные каталоги `dist/portable/0.3.0`, `dist/installers/0.3.0` и `dist/releases/0.3.0`. Скрипт проверяет встроенные иконки, настоящий Vosk из упакованной portable-папки, подписывает ZIP и NSIS, формирует отдельные манифесты и SHA-256. `build.json` содержит исходный коммит. Лицензия nnnoiseless/RNNoise включена в `models/Speech-Denoiser-NOTICE.txt`, совместимый с правилами обновления portable 0.2.0 путь.

Первый релизный прогон остановился с `rustc-LLVM ERROR: out of memory`. Профиль выпуска изменён на Thin LTO и 16 единиц генерации кода; скрипт по умолчанию ограничивает Cargo одним параллельным заданием и восстанавливает окружение после сборки. Уровень оптимизации остаётся релизным. Эти изменения относятся к сборке, а не к аудиопроверке.

Этот отчёт не подтверждает публикацию 0.3.0 в GitHub Releases. Ранее выполненная проверка установленного обновления NSIS относится к переходу на 0.2.0 и описана в [отдельном отчёте](./nsis-update-2026-11-14.md).
